# E0840: Invalid JSON-RPC Operation or Opaque Value Use

## Explanation

A `std.jsonrpc` operation has the wrong arity or argument types, or application
code attempted to construct, inspect, or mutate a runtime-owned
`JsonRpcMessage` or `JsonRpcDecoder` value.

These types are opaque validated values. Only `jsonrpc.decoder`,
`jsonrpc.feed`, `jsonrpc.parse`, and the envelope constructors create them.
Use `jsonrpc.value` and `jsonrpc.kind` to inspect a validated message.

## Error Example

```nomo
package app.main

import std.jsonrpc

fn main() -> void {
    let message: JsonRpcMessage = JsonRpcMessage { raw: "{}" }
}
```

## Correct Code

```nomo
package app.main

import std.json
import std.jsonrpc

fn main() -> void {
    let id: JsonValue = json.from_i64(1)
    let request: Result<JsonRpcMessage, JsonRpcProtocolError> =
        jsonrpc.request(id, "initialize", None)
}
```

## Fix

Use the exact signatures declared by `std.jsonrpc`. Obtain decoder states from
`decoder` and `feed`, and messages from `parse` or the request, notification,
success, and failure constructors.

Do not construct an opaque value or access its internal fields. Pass the
replacement decoder returned in `JsonRpcDecodeBatch.decoder` to the next
`feed` call, and use `finish` when the input stream reaches EOF.

# E0850: Opaque Cron Schedule Access

## Explanation

`CronSchedule` is a validated value owned by `std.cron`. Application code
cannot construct it with a struct literal, read its private expression field,
or assign that field. Only `cron.parse` can create a schedule.

## Error Example

```nomo
package app.main

import std.cron

fn main() -> void {
    let schedule: CronSchedule = CronSchedule { expression: "* * * * *" }
}
```

## Correct Code

```nomo
package app.main

import std.cron

fn main() -> void {
    let schedule: Result<CronSchedule, CronError> = cron.parse("* * * * *")
}
```

Use `cron.parse` to construct a validated schedule and pass the opaque value to
`cron.matches` or `cron.next_after`.

## Fix

Replace direct construction or field access with the public `std.cron`
functions. Propagate or handle the `CronError` returned by `cron.parse`,
`cron.matches`, and `cron.next_after`.

# E0860: Array Element Type Cannot Be Inferred

## Explanation

An empty array literal has no element from which the compiler can infer `T`.

## Error Example

```nomo
let values = []
```

## Correct Code

```nomo
let values: Array<i32> = []
```

## Fix

Add an `Array<T>` annotation or pass the literal to a context that already
expects `Array<T>`.

## LSP Code Action

No automatic code action is provided because the intended element type is
unknown.

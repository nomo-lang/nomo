# E0861: Incompatible Array Literal Elements

## Explanation

All elements of an array literal must have exactly the same type. Nomo does not
insert implicit numeric conversions.

## Error Example

```nomo
let values = [1, 2 as i64]
```

## Correct Code

```nomo
let values: Array<i64> = [1 as i64, 2 as i64]
```

## Fix

Use explicit casts so every element has the intended type. The compiler reports
the zero-based element position and both types.

## LSP Code Action

No automatic code action is provided because the intended numeric type is
ambiguous.

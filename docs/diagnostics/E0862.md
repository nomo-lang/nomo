# E0862: Indexed Value Is Not An Array

## Explanation

The `[]` operator is defined for `Array<T>` values. Each step in a nested index
path must also produce an array until the final element.

## Error Example

```nomo
let value: i32 = 1
let invalid = value[0]
```

## Correct Code

```nomo
let values = [1]
let valid: i32 = values[0]
```

## Fix

Index an array value or use the API of the actual value type.

## LSP Code Action

No automatic code action is provided.

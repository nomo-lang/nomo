# E0863: Malformed Array Index

## Explanation

An index expression requires one expression between `[` and `]` and a closing
bracket. Indexed assignment must be rooted in a local variable.

## Error Example

```nomo
let value = items[]
```

## Correct Code

```nomo
let value = items[0]
```

## Fix

Supply a `u64` index and close the bracket. For writes, assign through a mutable
local root such as `items[0] = value`.

## LSP Code Action

No automatic code action is provided.

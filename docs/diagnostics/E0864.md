# E0864: Immutable Indexed Assignment

## Explanation

Indexed assignment mutates the root array and therefore requires a `mut`
binding. This includes nested copy-on-write paths.

## Error Example

```nomo
let values = [1, 2]
values[0] = 7
```

## Correct Code

```nomo
let mut values = [1, 2]
values[0] = 7
```

## Fix

Declare the root binding with `let mut` when mutation is intended.

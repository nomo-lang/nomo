# E0865: Reserved Generic Map Name Collision

## Explanation

`std.map` monomorphizes a private implementation into the importing module.
Names beginning with `__nomo_map_` are reserved while that module is imported.

## Error Example

```nomo
import std.map

fn __nomo_map_get() -> void {
}
```

## Correct Code

Rename the application function so it does not use the reserved prefix.

## Fix

Use an application-owned name that does not begin with `__nomo_map_`.

## LSP Code Action

No automatic code action is provided.

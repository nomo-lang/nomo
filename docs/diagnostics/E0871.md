# E0871: Invalid Structured Task Scope

## Explanation

The structured `task.spawn target(args)` and one-argument `task.join(handle)`
forms require a lexical `task.scope { ... }`. The scope gives every child a
bounded owner and prevents work from silently outliving its parent.

## Error Example

```nomo
import std.task

suspend fn child() -> void {
}

suspend fn main() -> void {
    let handle = task.spawn child()
}
```

## Correct Code

```nomo
import std.task

suspend fn child() -> void {
}

suspend fn main() -> void {
    task.scope {
        let handle = task.spawn child()
        let joined: Result<void, TaskError> = task.join(handle)
    }
}
```

## Fix

Place structured spawn and join operations in a `task.scope` within a
`suspend fn`, and provide a braced scope body. The two-argument
`task.spawn(worker, input)` API is a separate legacy isolated-worker surface.

No automatic code action is provided.

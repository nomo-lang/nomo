# E0872: Invalid Scope-Owned Task Handle Use

## Explanation

A handle created by structured `task.spawn` belongs to its lexical
`task.scope`. It may be consumed once by `task.join` or structured
`task.cancel`; otherwise normal scope
fallthrough cancels and cleans it up automatically. It cannot escape, be
copied into another operation, or be joined/cancelled twice.

A final `return` and normal fallthrough cancel any unconsumed handles before
leaving the scope. A handle consumed by join or cancel cannot be used again.

## Error Example

```nomo
import std.task

suspend fn child() -> void {
}

suspend fn main() -> void {
    task.scope {
        let handle = task.spawn child()
        let first: Result<void, TaskError> = task.join(handle)
        let second: Result<void, TaskError> = task.join(handle)
    }
}
```

## Correct Code

```nomo
import std.task

suspend fn child() -> void {
}

suspend fn main() -> void {
    task.scope {
        let handle = task.spawn child()
        let joined: Result<void, TaskError> = task.join(handle)
    }
}
```

## Fix

Keep every scope-owned handle in its inferred immutable binding and join it at
most once, or cancel it once with an immutable
`let cancelled: Result<void, TaskError> = task.cancel(handle)` binding. Normal
fallthrough or a final scope `return` cancels and cleans up an unobserved
child. Pass a handle only to the one-argument structured `task.join` or
`task.cancel` operation.

# E0872: Invalid Scope-Owned Task Handle Use

## Explanation

A handle created by structured `task.spawn` belongs to its lexical
`task.scope`. The first P1 slice requires each handle to be consumed exactly
once by `task.join` before the scope exits. It cannot escape, be copied into
another operation, or be joined twice.

## Error Example

```nomo
import std.task

suspend fn child() -> void {
}

suspend fn main() -> void {
    task.scope {
        let handle = task.spawn child()
    }
}
```

## Correct Code

```nomo
import std.task

suspend fn child() -> void {
}

suspend fn main() -> void {
    task.scope {
        let handle = task.spawn child()
        let joined: Result<void, TaskError> = task.join(handle)
    }
}
```

## Fix

Join every scope-owned handle exactly once in the same scope. Keep the handle
in its inferred immutable binding and pass it only to the one-argument
structured `task.join`.

## LSP Code Action

No automatic code action is provided.

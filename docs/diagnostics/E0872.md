# E0872: Invalid Scope-Owned Task Handle Use

## Explanation

A handle created by structured `task.spawn` belongs to its lexical
`task.scope`. It may be consumed once by `task.join`; otherwise normal scope
fallthrough cancels and cleans it up automatically. It cannot escape, be
copied into another operation, or be joined twice.

A final `return` is valid only after all scope-owned handles have been joined.
Returning while a child is still live remains rejected until the early-control
transfer unwind slice lands.

## Error Example

```nomo
import std.task

suspend fn child() -> void {
}

suspend fn main() -> void {
    task.scope {
        let handle = task.spawn child()
        return
    }
}
```

## Correct Code

```nomo
import std.task

suspend fn child() -> void {
}

suspend fn main() -> void {
    task.scope {
        let handle = task.spawn child()
        let joined: Result<void, TaskError> = task.join(handle)
    }
}
```

## Fix

Keep every scope-owned handle in its inferred immutable binding. Join it before
using a scope `return`, or let normal scope fallthrough cancel and clean up the
unobserved child. Pass a handle only to the one-argument structured
`task.join`.

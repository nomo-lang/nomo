# E0875: Invalid Structured Task Target

## Explanation

The first structured spawn slice accepts a direct call to an unqualified,
top-level `suspend fn`. This keeps the child frame type and drop plan known to
the C99 backend without introducing closures or dynamic dispatch.

## Error Example

```nomo
import std.task

fn child() -> void {
}

suspend fn main() -> void {
    task.scope {
        let handle = task.spawn child()
        let joined: Result<void, TaskError> = task.join(handle)
    }
}
```

## Correct Code

```nomo
import std.task

suspend fn child() -> void {
}

suspend fn main() -> void {
    task.scope {
        let handle = task.spawn child()
        let joined: Result<void, TaskError> = task.join(handle)
    }
}
```

## Fix

Declare the target as an unqualified top-level `suspend fn` and use the direct
`task.spawn child(args)` form. The current slice does not accept a function
value, method, qualified path, or closure as the target.

No automatic code action is provided.

# E0876: Unsupported Suspension Shape

## Explanation

The current P1 runtime slice lowers `task.yield_now()`, `let`-bound
`task.sleep(Duration)` results, and direct calls between non-generic actually
suspending functions. Immutable frame-safe parameters evaluate once into the
child frame, and value results move into an immutable top-level `let` before
child drop. Each function call site embeds one child frame; recursive suspend
graphs would need dynamically sized frames and remain unsupported.

The first structured-concurrency slice additionally lowers a top-level
`task.scope` containing inferred immutable
`task.spawn child(args)` handles and exactly one
`task.join(handle) -> Result<T, TaskError>` per child. Child targets must be
non-generic top-level suspend functions with immutable parameters and a
frame-safe result type.

Immutable top-level locals may live across suspension when all transitive value
fields are frame-safe. Mutable parameters/locals, borrows, guards, resource
handles or wrappers containing them, `?`, explicit panic, nested control flow,
suspending argument expressions, nested task scopes, structured child results
that are not frame-safe, or other nested suspending expressions need transfer
or unwind rules that are not implemented yet. Async `main` also remains
`void` until its result-to-process-status ABI lands.

This diagnostic prevents the compiler from silently generating synchronous or
incorrect C99 code for a suspension shape that the runtime cannot preserve.

## Error Example

```nomo
import std.task

suspend fn helper(mut value: string) -> string {
    task.yield_now()
    return value
}

suspend fn main() -> void {
    let value: string = helper("ready")
}
```

## Correct Code

For this implementation slice, bind value-returning suspend calls and
`task.sleep` with immutable top-level `let` declarations. Immutable frame-safe
parameters, results, and locals may cross either boundary:

```nomo
import std.io
import std.task
import std.time

suspend fn helper(message: string) -> string {
    let waited: Result<void, TaskError> = task.sleep(time.duration_millis(10))
    return message
}

suspend fn main() -> void {
    let message: string = helper("ready")
    io.println(message)
}
```

## Fix

Keep the suspend call chain acyclic and non-generic; bind every value-returning
suspend call and `task.sleep` result. Move suspensions out of control flow,
nested expressions, and argument expressions, and keep parameters/results plus
cross-suspension locals immutable and frame-safe. In `task.scope`, use only
top-level immutable spawn/join bindings and frame-safe child results for this
slice. Wait for the later mutable or affine transfer, control-flow, and
complete unwind slices when those semantics are required. Do not replace a
required nonblocking boundary with a blocking operation merely to avoid the
diagnostic.

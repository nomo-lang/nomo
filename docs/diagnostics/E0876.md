# E0876: Unsupported Suspension Shape

## Explanation

The current P1 runtime slice lowers `task.yield_now()` only when it is a
standalone statement in a parameterless root `suspend fn main() -> void`.
Immutable top-level locals may live across yields when all transitive value
fields are frame-safe. Mutable locals, borrows, guards, resource handles or
wrappers containing them, `?`, explicit panic, suspension inside another
function, nested control flow, a local initializer, an argument, or another
expression need frame or unwind rules that are not implemented yet.

This diagnostic prevents the compiler from silently generating synchronous or
incorrect C99 code for a suspension shape that the runtime cannot preserve.

## Error Example

```nomo
import std.task

suspend fn helper() -> void {
    task.yield_now()
}

suspend fn main() -> void {
    helper()
}
```

## Correct Code

For this implementation slice, keep the yield as a direct root statement.
Immutable top-level locals may cross it:

```nomo
import std.io
import std.task

suspend fn main() -> void {
    let message: string = "ready"
    task.yield_now()
    io.println(message)
}
```

## Fix

Move the suspension to the root `suspend fn main() -> void`, keep cross-yield
locals immutable and within the supported value types, or wait for the later
nested-frame and complete unwind implementation before using that shape.
Do not replace a required nonblocking boundary with a blocking operation merely
to avoid the diagnostic.

## LSP Code Action

No automatic code action is provided.

# E0876: Unsupported Suspension Shape

## Explanation

The current P1 runtime slice lowers `task.yield_now()`, `let`-bound
`task.sleep(Duration)` results, and direct calls to parameterless actually
suspending functions in non-generic, parameterless `suspend fn` functions
returning `void`. Each function call site embeds one child frame; recursive
suspend graphs would need dynamically sized frames and remain unsupported.

Immutable top-level locals may live across suspension when all transitive value
fields are frame-safe. Mutable locals, borrows, guards, resource handles or
wrappers containing them, general suspend arguments/results, `?`, explicit
panic, nested control flow, suspending initializers other than `task.sleep`, a
suspending argument expression, or another suspending expression need frame,
result, or unwind rules that are not implemented yet.

This diagnostic prevents the compiler from silently generating synchronous or
incorrect C99 code for a suspension shape that the runtime cannot preserve.

## Error Example

```nomo
import std.task

suspend fn helper(value: string) -> string {
    task.yield_now()
    return value
}

suspend fn main() -> void {
    let value: string = helper("ready")
}
```

## Correct Code

For this implementation slice, keep each user-function suspension as a
standalone direct-style call. Bind the result of `task.sleep`; immutable
top-level locals may cross either boundary:

```nomo
import std.io
import std.task
import std.time

suspend fn helper() -> void {
    let message: string = "ready"
    let waited: Result<void, TaskError> = task.sleep(time.duration_millis(10))
    io.println(message)
}

suspend fn main() -> void {
    helper()
}
```

## Fix

Keep the suspend call chain acyclic, parameterless, and `void`-returning; bind
each `task.sleep` result, move other suspensions out of control flow,
initializers, arguments, and expressions, and keep cross-suspension locals
immutable and within the supported value types. Wait for the later general
parameter/result, control-flow, and complete unwind slices when those semantics
are required. Do not replace a required nonblocking boundary with a blocking
operation merely to avoid the diagnostic.

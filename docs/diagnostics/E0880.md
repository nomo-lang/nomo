# E0880: Local Value Crosses a Publication Boundary

## Explanation

A structured `task.spawn child(args)` argument is a compiler-known
publication position, but the argument type owns a Local/!Send runtime
resource.

Files, sockets, HTTP server/exchange/stream handles, controlled process
children, SQLite handles, task handles, and FFI handles remain bound to their
owner runtime. The diagnostic reports only type and field names; it does not
inspect or print the runtime value.

## Error Example

```nomo
import std.fs
import std.task

suspend fn consume(file: File) -> void {
    task.yield_now()
}

suspend fn launch(file: File) -> void {
    task.scope {
        let child = task.spawn consume(file) // E0880
        let joined: Result<void, TaskError> = task.join(child)
    }
}
```

## Correct Code

Publish copied or owned data while keeping the resource on its owner task:

```nomo
import std.task

suspend fn consume(message: string) -> void {
    task.yield_now()
}

suspend fn launch(message: string) -> void {
    task.scope {
        let child = task.spawn consume(message)
        let joined: Result<void, TaskError> = task.join(child)
    }
}
```

## Fix

Extract Send data from the resource before the publication boundary, or keep
the operation on its owner task. Do not wrap the handle in another struct to
hide it; structural derivation reports E0883 for the first nested Local field.

## LSP Code Action

No automatic code action is provided.

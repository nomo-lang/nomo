# E0886: Invalid Static Select Shape

## Explanation

The P3-C/P3-D `task.select` surface is intentionally static. A select must have
2 through 8 arms, and each operation must be a direct
`task.receive(Channel<T>)`, `task.send(Channel<T>, T)`,
`task.sleep(Duration)`, or `task.join(Task<T>)` call followed by an immutable
result binding and a non-empty lexical body.

This diagnostic keeps dynamic arm lists and malformed or empty selects from
being lowered as sequential operations.

## Error Example

```nomo
task.select {
    task.receive(messages) => message {
        consume(message)
    }
}
```

The select has only one arm.

## Correct Code

```nomo
task.select {
    task.receive(messages) => message {
        consume(message)
    }
    task.sleep(time.duration_millis(50)) => timeout {
        observe(timeout)
    }
}
```

## Fix

Use 2 through 8 direct receive, send, timer, or join arms. Keep each arm body
non-empty. E0876 covers arm bodies that contain unsupported nested exits,
suspension, or nested structured forms. E0887 covers staged send values or
affine join handles used again after the select boundary.

No automatic code action is provided.

# E0886: Invalid Static Select Shape

## Explanation

The first P3-C `task.select` slice is intentionally static. A select must have
2 through 8 arms, and each operation must be a direct
`task.receive(Channel<T>)` or `task.sleep(Duration)` call followed by an
immutable result binding and a non-empty lexical body.

This diagnostic keeps unsupported send/join selection, dynamic arm lists, and
malformed or empty selects from being lowered as sequential operations.

## Error Example

```nomo
task.select {
    task.receive(messages) => message {
        consume(message)
    }
}
```

The select has only one arm.

## Correct Code

```nomo
task.select {
    task.receive(messages) => message {
        consume(message)
    }
    task.sleep(time.duration_millis(50)) => timeout {
        observe(timeout)
    }
}
```

## Fix

Use 2 through 8 direct receive or timer arms. Keep each arm body non-empty.
E0876 covers arm bodies that contain unsupported early exits, nested
suspension, or nested structured forms.

## LSP Code Action

No automatic code action is provided.

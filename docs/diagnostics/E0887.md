# E0887: Select Ownership Was Reused

## Explanation

A static `task.select` evaluates every arm operand exactly once before
readiness is resolved. A named non-Copy value passed to `task.send` is staged
and publication-moved at that boundary. It is unavailable after the select
even when another arm wins. A `task.join` handle is affine for the same reason
and cannot be joined, cancelled, or selected again afterward.

A losing staged send value is released exactly once. A losing join arm only
unregisters its waiter; it does not cancel the child. The child remains owned
by the enclosing `task.scope` and is completed by the scope's mandatory
implicit cleanup if no winning path consumed its result.

## Error Example

```nomo
task.scope {
    let child = task.spawn produce()
    task.select {
        task.join(child) => joined {
            consume(joined)
        }
        task.sleep(timeout) => elapsed {
            observe(elapsed)
        }
    }
    let joined_again: Result<string, TaskError> = task.join(child)
}
```

## Correct Code

Handle the typed result inside the winning arm, or restructure the scope so a
handle or value crosses only one publication/consumption boundary:

```nomo
task.scope {
    let child = task.spawn produce()
    task.select {
        task.join(child) => joined {
            consume(joined)
        }
        task.sleep(timeout) => elapsed {
            observe(elapsed)
        }
    }
}
```

## Fix

Move all uses of a staged send value or selected join result into the
corresponding winning arm. If later code must observe a common outcome, return
or store a separate value from each arm instead of reusing the consumed input
or handle.

## 中文说明

静态 `task.select` 会在判断 readiness 前按源码顺序对全部 arm operand
恰好求值一次。传给 `task.send` 的具名非 Copy value 会在该边界 staged 并
publication-move；即使其他 arm 获胜，select 之后也不能再次使用。参与
`task.join` 的 handle 同样是 affine，之后不能再次 join、cancel 或 select。

losing send 的 staged value 只会 release 一次。losing join 只注销 waiter，
不会取消 child；child 仍归外层 `task.scope` 所有，并在没有 winner 消费其
result 时由 scope 的强制隐式清理完成。

# E0904: Module Package Mismatch

## Explanation

An entry point or imported module file was found, but its `package` declaration
does not match the manifest-derived module root and source path. The compiler
does not infer a project root from the entry source declaration.

For example, package name `hello-world` derives module root `hello_world`.
`src/main.nomo` declares `package hello_world`, `src/math.nomo` declares
`package hello_world.math`, and `src/http/main.nomo` declares `package
hello_world.http`.

## Error Example

```nomo
package hello_world.other

pub fn add(a: i64, b: i64) -> i64 {
    return a + b
}
```

when the file is loaded through:

```nomo
import hello_world.math
```

## Correct Code

```nomo
package hello_world.math

pub fn add(a: i64, b: i64) -> i64 {
    return a + b
}
```

## Fix

Run `nomo fix module-roots [path]`, update the declaration to match the source
path, or move the file so the path and declaration agree.

## LSP Code Action

Yes. When `nomo-lsp` can infer the expected module path from the current file
location, it exposes a quick fix that updates the `package` declaration.

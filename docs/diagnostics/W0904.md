# W0904: Legacy Module Package Declaration

## Explanation

The compiler accepted a pre-migration module declaration such as `package
app.main`, `package app.math`, or `package <manifest_root>.main`. This is a
one-development-snapshot compatibility window. Canonical declarations are
derived from `[package].name` in `nomo.toml` and the source path.

## Error Example

```nomo
package app.main

fn main() {
}
```

## Correct Code

For a manifest package named `hello-world`:

```nomo
package hello_world

fn main() {
}
```

## Fix

Run `nomo fix module-roots [path]`. Use `--check` in CI. The compatibility
window is removed in the first development snapshot after all maintained
repositories pass this check.

## LSP Code Action

Yes. Tooling may apply the same package-declaration replacement as `nomo fix
module-roots`.
